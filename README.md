# porcube.github.io

ボードゲーム制作サークル PORCUBE（ぽるきゅーぶ）の公式サイト。

## 作品・イベント・メンバーを更新するとき

1. `js/data.js` を編集する
2. ビルドを実行する

   ```
   node tools/build.js
   ```

3. 生成・更新されたファイル（`index.html`、`games/*.html`、`sitemap.xml`）もあわせてコミットする

ビルドは、検索エンジンが読めるように data.js の内容を HTML に書き出す処理です。
ビルドを忘れてもトップページの見た目は data.js の内容で表示されますが、作品ページと検索結果には反映されません。

- `games/*.html` は自動生成です。直接編集せず `js/data.js` を編集してください。
- エラッタ・よくある質問は `errata.html` を直接編集します（書き方はファイル内のコメント参照）。
